# Scoped and transactional writes

Map three things together: required effects and durable replay; existing rows and multiplicities outside the write set; valid ignored conflicts, no-ops and internal row moves. Compare contract identities and values, not physical rowids. Keep account and receipt lookups within the authorized scope, including preservation queries and aggregates. Storage-local observation of actual OLD/NEW effects can prove preservation without fetching foreign stored rows.

**Prove the hardest write boundary before building out the happy path.** Check the available binding once. Use one small runtime probe pairing a destructive effect with a valid control to select an observer that sees actual row effects and implicit deletions. Implement and exercise that slice before expanding the suite. A passing transaction test alone does not establish the frame. If blocked by a failing mechanism check, keep the working slice and record the exact gap for review or a bounded repair.

For SQLite, BEFORE runs even for ignored attempts; ordinary update hooks and change counts can miss REPLACE victims. Cover arbitrary existing UNIQUE indexes as well as primary keys and rowids. Prefer supported actual-effect hooks where exposed. AFTER OLD can be stale when a BEFORE trigger modifies the same row: summing OLD/NEW deltas is unsound. With a trigger journal, first prove observer ordering and reconcile each physical slot's chronological initial/latest image, using the observed latest image for subsequent removals; track absence, replacement and row moves, then compare typed logical multisets. Test an unrelated-row change/restore/change sequence and its valid change/restore control. Do not read foreign rows into the application to repair observation gaps.

If SQLite trigger instrumentation is necessary, preserve SQL spans and use the installed engine to validate candidate boundaries. Before committing to a lexer, run one native-versus-instrumented batch for keyword and Unicode identifiers, a conditional compound body, and legal separators. Check vertical tab and token-boundary U+FEFF separately from U+00A0 and embedded U+FEFF inside an unquoted identifier. Host-language whitespace classes conflate these cases. SQLite also accepts single-quoted names in table-reference context; when normalizing callable pragma sources through views, preserve name resolution, schema qualifiers, aliases, literal strings and scalar expressions. Verify implicit-delete observation without changing the original recursion setting observed by user SQL. Execute aborting and harmless guards; successful CREATE alone does not resolve every body reference. Preserve execution order, ignored statements, trigger-visible change counters and last-insert state; restore exact definitions transactionally.

Before commit verify required effects and the frame. Exercise the public interface and induce a storage failure after an earlier write to verify complete rollback. Check unchanged history and replay after reopening, scope with malformed foreign data, and concurrency where required. Keep error assertions tied to the contract. Fresh review reruns the required checks and independently challenges the chosen mechanism with a valid/invalid pair; repair and review the demonstrated delta within the same REWORK count.
