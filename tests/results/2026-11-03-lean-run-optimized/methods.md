# Optimized lean-run comparison — 2026-11-03

## Change under test

The entrypoint shrank from 16,484 to 8,819 characters (46.50%), and from 2,365 to 1,159 whitespace-delimited words. These are instruction-size measures, not estimated runtime tokens. That static review is separate from the measured task trials. All 11 repository checks, the skill validator and 34 installation scenarios passed before freezing this candidate.

## Controls and accounting

The same synthetic tasks ran sequentially medium → high → critical, with one fresh implementation session and one fresh independent review session per level; any necessary repair/review must be retained and counted. Requested model/effort remained gpt-6-astra / max, procedure depth standard, CLI 0.166.0, Python 3.14.3, SQLite 3.50.4 and macOS 27.0.1 arm64. Backend identity is not independently attested. Existing ChatGPT authentication was reused without a new API key or provider change.

Initial application files, contracts, AGENTS.md and public tests, both phase prompts, and the frozen 4/6/9-category grader are byte-identical to the retained baseline. Only the supplied skill package changed. Candidate hashes were frozen before the first launch; no skill revisions occurred between measured levels. All work uses isolated local fixtures, with no live services or real payments. Read boundaries are instructional, not OS-enforced secrecy.

Elapsed time is monotonic time around each CLI process, including startup, model processing and tools. Workflow totals include implementation, review and all repairs/reviews. First-pass totals are also reported to separate changed repair incidence. Coordinator chat, static skill review, setup, graders, cross-regression checks and report generation are excluded. Thus the totals are not complete chat elapsed time or account usage.

Tokens are recomputed from archived turn.completed.usage events. Total = input + output; cached input is already included in input and reasoning is already included in output. Uncached input + output is reported as a count, not a price estimate. Runtime prompt caches and remote service load were not controlled. The 900-second phase timeout remained unchanged; there was no hard token cap.

## Quality checks

Keep distinct measures separate: failed frozen contract categories, distinct independent-review findings, and supplemental regression results. Do not add overlapping counts as if they were independent bugs. Reviews receive only the contract, original/current source and tests, not author conclusions, hidden grades or historical findings. Review workspace hashes detect changes. The previous critical silent-write finding is checked separately using the exact retained four-point supplemental probe, after the first review, without changing the frozen grader.

Both historical and new regression suites run against the other implementation in disposable directories. Raw logs are retained even when a test asserts something beyond the contract. Medium's historical suite requires the word “argument” in four arity-error subcases; the new implementation explains “expected exactly one comma-separated integer list” and passes all exit/stdout/stderr/traceback checks. That wording restriction is absent from the contract. No tests or application code were changed to suppress the raw failures; the adjudication is retained separately.

## Limits

This is one observed run per level for each version, with no variance estimate or randomized A/B order. Improvements cannot be attributed solely to the skill: model nondeterminism, caching, service latency and whether a repair was necessary affect the measurements. Retesting the same tasks demonstrates these contracts and regressions; it does not establish general quality equivalence on unseen tasks or autonomous nested delegation. All source and raw evidence are retained so the comparison can be repeated.
